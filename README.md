# midnight-clocktower-resourcepack
Minecraft Java 26.3 자정의 시계탑 — 괴도의 예고장 (스토리 단타) 리소스팩 배포

서버가 접속할 때 알아서 받게 하는 팩입니다. 기본 Minecraft 26.3 클라이언트에서 동작합니다. 내려받기는 Releases에 있습니다.

## 글꼴
팩에 포함한 글꼴이며, 모두 SIL Open Font License 1.1을 따릅니다. (https://openfontlicense.org)

- Gowun Batang (`assets/film/font/gowunbatang-regular.ttf`, `assets/film/font/gowunbatang-bold.ttf`)
- Gowun Dodum (`assets/film/font/gowundodum-regular.ttf`)
- Nanum Pen Script (`assets/film/font/nanumpenscript-regular.ttf`)
- Poiret One (`assets/film/font/poiretone-regular.ttf`)

## 음악
`assets/film/sounds/` 의 곡은 「명탐정 코난」 OST(오노 카츠오)와 오프닝 곡에서 잘라 쓴 것입니다. 저작권은 원저작자에게 있으며, 비상업 팬 서버에서만 씁니다.

## 효과음 · 음성
- `assets/film/sounds/` 의 효과음 · 바닥 소리 일부는 BigSoundBank(https://bigsoundbank.com)의 실제 녹음입니다. CC0(퍼블릭 도메인)입니다.
- '번뜩' 효과음은 「명탐정 코난」 애니메이션의 효과음에서 잘라 쓴 것입니다. 저작권은 원저작자에게 있으며, 비상업 팬 서버에서만 씁니다.
- 기자 중계 목소리는 합성 음성(Microsoft Edge 소리 내어 읽기, ko-KR-SunHiNeural)으로 만들었습니다.
